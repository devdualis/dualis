# Plan 10-02: Mobile Privacy Center UI, Confirmation Safeguards, Local SQLite Wipe & Production Verification

## Threat Model
| Threat | Mitigation |
|--------|------------|
| Accidental permanent account deletion | High-friction modal requiring explicit password input and confirmation dialog |
| Residue health data remaining on device after account deletion | Cascade deletion to local Drift SQLite database (`triageOutbox`, `localSymptomDrafts`) and hardware SecureStorage keys |

## Tasks

### Task 10-02-01: Implement Privacy Data Source, Controller, and Trilingual Keys
- Add endpoints `exportData = '/v1/auth/export-data'` and `deleteAccount = '/v1/auth/account'` in `ApiEndpoints`.
- Add copywriting keys to `app_pt.arb`, `app_es.arb`, and `app_en.arb`. Run `flutter gen-l10n`.
- Implement `PrivacyRemoteDataSource` calling export and deletion endpoints with token authorization.
- Implement `PrivacyController` handling data export, permanent deletion call, local Drift database wipe, and session cleanup.
