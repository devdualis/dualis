# Plan 09-01: Backend Historical Feeds & Screen 7 Physical Vertical (2D Body Heat Map)

## Threat Model
| Threat | Mitigation |
|--------|------------|
| Cross-tenant data leakage in historical retrieval (SEC-01) | Enforce PostgreSQL RLS via `DatabaseService.runWithTenantContext` setting `app.current_user_id = :userId` on every query |
| Unbounded history query memory consumption | Default to 14 days, max 30 days query clamp |

## Tasks

### Task 09-01-01: Implement Backend Triage History Service & Endpoint (`GET /v1/triage/history`)
- Implement `backend/src/modules/triage/dto/triage-history.dto.ts` with query and response DTOs (`TriageHistoryResponseDto`, `TriageLogEntryDto`, `PhysicalSummaryDto`, `EmotionalSummaryDto`, `CriticalRecurrenceDto`).
- Implement `backend/src/modules/triage/services/triage-history.service.ts` querying `symptom_logs` under RLS for the past 14 days, computing:
  - Max intensity per 12 anatomical systems
  - Daily aggregated emotional intensity per dimension for last 7 days
  - Critical recurrence conditions (e.g. intensity >= 4 on >= 6 of last 10 days)
- Register service and controller method `GET /v1/triage/history` with `JwtAuthGuard` in `backend/src/modules/triage/triage.controller.ts` and `triage.module.ts`.
- Write unit tests in `backend/test/unit/triage-history.service.spec.ts` and E2E tests in `backend/test/e2e/triage-history.e2e-spec.ts`.
- Verify tests pass.

### Task 09-01-02: Implement Mobile Triage History Domain Models & Data Source
- Implement `mobile/lib/features/dashboard/domain/models/triage_history_models.dart` (`TriageHistoryResponse`, `TriageHistoryEntry`, `AnatomicalSystemIntensity`, `CriticalRecurrenceItem`).
- Implement `mobile/lib/features/dashboard/data/triage_history_remote_data_source.dart` calling `GET /v1/triage/history` with Dio, handling network errors with local Drift SQLite fallback.
- Write unit tests in `mobile/test/features/dashboard/triage_history_models_test.dart`.
- Verify tests pass.

### Task 09-01-03: Implement 2D Anatomical Body Map with Pain Heat Gradients & Retrospective List
- Implement `mobile/lib/features/dashboard/presentation/widgets/anatomical_body_map.dart` with `CustomPainter` rendering human silhouette with 12 distinct anatomical regions:
  - Neutral grey (`#CFD8DC`) for 0
  - Mild yellow (`#FFD54F`) for 1–2
  - Moderate orange (`#FF8A65`) for 3
  - Severe crimson (`#E53935`) for 4–5
  - Interactive selection showing tapped region details and legend bar.
- Implement `mobile/lib/features/dashboard/presentation/widgets/retrospective_list_view.dart` rendering chronological past entries.
- Write widget test in `mobile/test/features/dashboard/anatomical_body_map_test.dart`.
- Verify tests pass.
