# Plan 09-02: Screen 7 Emotional Vertical, 7-Day Trend Graph, Cards de Recorrência Crítica & Tab Navigation

## Threat Model
| Threat | Mitigation |
|--------|------------|
| Chart rendering crash on empty history | Fallback to empty state banner with informative guidance |
| High memory use with heavy canvas chart | Auto-dispose controller and keep 7-day data points light |

## Tasks

### Task 09-02-01: Add fl_chart Dependency & Trilingual Localization
- Add `fl_chart: ^1.2.0` to `mobile/pubspec.yaml`. Run `flutter pub get`.
- Add all Screen 7 copywriting keys to `mobile/lib/l10n/app_pt.arb`, `app_es.arb`, and `app_en.arb`.
- Run `flutter gen-l10n` and verify static analysis.

### Task 09-02-02: Implement 7-Day Emotional Trend Chart & Cards de Recorrência Crítica
- Implement `mobile/lib/features/dashboard/presentation/widgets/emotional_trend_chart.dart` using `LineChart` from `fl_chart`:
  - 7 dates on X-axis, 1-5 intensity on Y-axis
  - Series for active dimensions with distinct palette
  - Touch tooltips showing date, dimension, intensity
  - Clean legend
- Implement `mobile/lib/features/dashboard/presentation/widgets/critical_recurrence_card.dart`:
  - Prominent attention container (`#FFF8E1`, border `#FFE082`)
  - Warning icon, headline, and article recommendation CTA button
- Implement `mobile/lib/features/dashboard/presentation/widgets/dashboard_segmented_tab.dart`:
  - Segmented control toggling between Soft Indigo (`#3F51B5`) and Clinical Teal (`#00796B`)
- Write widget tests in `mobile/test/features/dashboard/emotional_trend_chart_test.dart` and `mobile/test/features/dashboard/critical_recurrence_card_test.dart`.

### Task 09-02-03: Implement Historical Dashboard Screen, State Controller & Home Navigation
- Implement `mobile/lib/features/dashboard/presentation/controllers/dashboard_controller.dart` managing `AsyncValue<DashboardState>`.
- Implement `mobile/lib/features/dashboard/presentation/screens/historical_dashboard_screen.dart`:
  - AppBar with title, segmented tab bar, pulling refresh indicator
  - Displays Physical vertical (Body Heat Map + Physical Recurrence + Physical Retrospective List) or Emotional vertical (7-Day Trend Chart + Emotional Recurrence Cards + Emotional Retrospective List)
- Add `RoutePaths.history` in `mobile/lib/core/router/route_paths.dart` and register `/history` in `app_router.dart`.
- In `mobile/lib/features/home/presentation/screens/home_screen.dart`, add quick access button / icon to navigate to `/history`.
- Write widget tests in `mobile/test/features/dashboard/historical_dashboard_screen_test.dart`.
- Run full test suite (`flutter test` and backend tests), hot restart via DTD, and verify 100% green.
