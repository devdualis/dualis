# Plan 08-01: Drift SQLite Database Setup, Local Outbox Schema, and Backend Idempotency Support

**Phase:** 8 — Offline Caching & Outbox Synchronization  
**Plan:** 08-01  
**Requirements covered:** SYNC-01  
**Mode:** mvp  

---

## Goal

Establish the local persistent SQLite storage tier with Drift and backend idempotency protection:
1. Update NestJS backend with `clientSessionId` support in `symptom_logs` for idempotent submission handling.
2. Add Drift SQLite and connectivity dependencies to `mobile/pubspec.yaml`.
3. Create `AppDatabase` with `TriageOutbox` and `LocalSymptomDrafts` tables.
4. Implement `TriageOutboxRepository` managing the outbox queue lifecycle.
5. Automated database tests and backend idempotency E2E tests.

---

## Tasks

### T1 — Backend Idempotency Migration and Service Support
**Files:** `backend/src/database/migrations/0006_symptom_logs_client_session_id.sql` [NEW], `backend/src/database/schema/symptom-logs.schema.ts` [MODIFY], `backend/src/modules/triage/dto/create-triage-outcome.dto.ts` [MODIFY], `backend/src/modules/triage/services/triage-outcome.service.ts` [MODIFY]
Add `client_session_id` column to `symptom_logs`. If `clientSessionId` is supplied and matches an existing record for the authenticated patient, return the existing outcome without inserting a duplicate record.

### T2 — Add Mobile Drift & Connectivity Dependencies
**File:** `mobile/pubspec.yaml` [MODIFY]
Add `drift: ^2.22.0`, `drift_flutter: ^0.2.0`, `connectivity_plus: ^6.1.3`, `uuid: ^4.5.1`, and dev dependency `drift_dev: ^2.22.0`. Run `flutter pub get`.

### T3 — Implement Drift AppDatabase & Tables
**File:** `mobile/lib/core/database/app_database.dart` [NEW]
Define Drift tables `TriageOutbox` and `LocalSymptomDrafts`. Run `dart run build_runner build --delete-conflicting-outputs` to generate `app_database.g.dart`.

### T4 — Implement TriageOutboxRepository
**File:** `mobile/lib/features/sync/data/triage_outbox_repository.dart` [NEW]
Repository providing methods: `enqueueTriageCheckIn(...)`, `getPendingOutboxItems()`, `updateOutboxStatus(...)`, `markOutboxItemSynced(...)`, and `getPendingCountStream()`.

### T5 — Automated Database and Backend E2E Tests
**Files:** `mobile/test/core/database/app_database_test.dart` [NEW], `backend/test/e2e/outbox-idempotency.e2e-spec.ts` [NEW]
Verify FIFO order in outbox, state transitions, and backend duplicate submission idempotency.
