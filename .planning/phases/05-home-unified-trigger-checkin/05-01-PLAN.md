# Plan 05-01: Screen 3 Home UI with Dual-Axis Trigger Flow, Wellness Confirmation & Privacy AdMob Container

**Phase:** 5 — Home & Unified Dual-Axis Trigger Check-in (Screen 3 / RF-001) & AdMob Container (RF-009)
**Plan:** 05-01
**Requirements covered:** TRG-01, AD-01, I18N-02 (UI)
**Mode:** mvp

---

## Goal

Build the Screen 3 Home experience implementing the mandatory dual-axis trigger check-in (*"Como você está se sentindo hoje?"* across Psico-Emocional and Avaliação Física axes), the 3-option selectors (`[Bem / Normal]`, `[Mais ou menos]`, `[Mal / Ruim]`), immediate wellness confirmation when both are well, Organic Primacy routing when both report discomfort, natural language symptom intake field, and the privacy-preserving AdMob container widget.

---

## Tasks

### T1 — Create `TriggerStatus` and `TriggerCheckInState`
**File:** `mobile/lib/features/home/domain/trigger_checkin_state.dart` [NEW]
Define `TriggerStatus` (`goodNormal`, `soSo`, `badSick`) and `TriggerCheckInState` tracking emotional and physical selections, free-text input, and submission state.

### T2 — Create `TriggerCheckInNotifier`
**File:** `mobile/lib/features/home/presentation/controllers/trigger_checkin_controller.dart` [NEW]
Riverpod `Notifier<TriggerCheckInState>` managing selection of emotional status, physical status, text input, and routing determination according to the clinical matrix.

### T3 — Create `DualAxisTriggerCard` widget
**File:** `mobile/lib/features/home/presentation/widgets/dual_axis_trigger_card.dart` [NEW]
Displays the 2 parallel assessment tracks with distinct icons, color highlights, and 3 options each.

### T4 — Create `WellnessConfirmationDialog`
**File:** `mobile/lib/features/home/presentation/widgets/wellness_confirmation_dialog.dart` [NEW]
Shown when both axes are `[Bem / Normal]`, delivering positive preventive feedback with zero triage friction.

### T5 — Create `AdMobBannerContainer` widget
**File:** `mobile/lib/features/home/presentation/widgets/admob_banner_container.dart` [NEW]
Native Material 3 container for local commerce banners with LGPD privacy badge ("Anúncio contextual local • Zero rastreamento clínico").

### T6 — Update `HomeScreen`
**File:** `mobile/lib/features/home/presentation/screens/home_screen.dart` [MODIFY]
Incorporate `DualAxisTriggerCard`, natural language input with chips, Organic Primacy routing, and `AdMobBannerContainer`.

### T7 — Add ARB localization keys
**Files:** `mobile/lib/l10n/app_pt.arb`, `app_es.arb`, `app_en.arb` [MODIFY]
Add localized strings for dual-axis questions, 3 status labels, wellness confirmation, and AdMob privacy label.

### T8 — Widget & unit tests
**File:** `mobile/test/features/home/trigger_checkin_test.dart` [NEW]
Verify both good/normal -> wellness dialog, single axis -> direct triage, both distressed -> organic primacy routing (physical first).
