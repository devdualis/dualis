# Plan 05-02: Gemini 1.5 Flash Structured JSON Classification Service with Latency SLA Validation

**Phase:** 5 — Home & Unified Dual-Axis Trigger Check-in (Screen 3 / RF-001) & AdMob Container (RF-009)
**Plan:** 05-02
**Requirements covered:** TRG-02, I18N-02
**Mode:** mvp

---

## Goal

Implement the NestJS AI classification service using Gemini 1.5 Flash with strict JSON Schema output, sub-2s latency SLA (`RNF-002`), an in-memory/Redis semantic cache, and a deterministic clinical idiom dictionary (*"nó na garganta"*, *"peito apertado"*, *"cabeça explodindo"*) ensuring resilient sub-10ms classification even under network constraints.

---

## Tasks

### T1 — Install dependencies & configure AI schema
**File:** `backend/package.json` [MODIFY]
Add `@google/genai` (or appropriate SDK).

### T2 — Create AI DTOs & Contracts
**File:** `backend/src/modules/ai/dto/classify-symptom.dto.ts` [NEW]
Define request `ClassifySymptomDto` (`text: string`, `language?: 'pt' | 'es' | 'en'`) and response `TriageClassificationResponseDto` (`vertical: 'physical' | 'emotional'`, `systemOrDimension: string`, `urgencyScore: number`, `mappedLayTerm: string`, `clinicalConcept: string`, `isEmergencyCandidate: boolean`).

### T3 — Implement Idiom Dictionary Fallback Service
**File:** `backend/src/modules/ai/services/idiom-dictionary.service.ts` [NEW]
Fast-path lookup engine with 35+ trilingual medical distress idioms mapping colloquial expressions to formal clinical categories in <5ms.

### T4 — Implement Gemini Triage Service
**File:** `backend/src/modules/ai/services/gemini-triage.service.ts` [NEW]
Invokes Gemini 1.5 Flash with strict structured JSON schema, caching responses, and falling back gracefully to the idiom dictionary if external API quota/keys are unavailable.

### T5 — Create AI Controller
**File:** `backend/src/modules/ai/ai.controller.ts` [NEW]
Expose `POST /v1/ai/classify-symptom` guarded by JWT authentication.

### T6 — Register `AiModule`
**File:** `backend/src/modules/ai/ai.module.ts`, `backend/src/app.module.ts` [NEW/MODIFY]
Register controllers and services in NestJS application dependency injection.

### T7 — Automated Tests
**Files:** `backend/test/unit/ai.service.spec.ts` [NEW] and `backend/test/e2e/ai.e2e-spec.ts` [NEW]
Verify classification accuracy, emergency candidate detection, idiom mapping, and sub-2s SLA validation.
