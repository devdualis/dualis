# Plan 07-01: Temporal Index Optimization, Longitudinal Consistency Evaluation, and Biological Boundary Engine

**Phase:** 7 — Antiburla Historical Verification Sheet (Screen 5 / RF-003 & UC-01)
**Plan:** 07-01
**Requirements covered:** ANTI-01, ANTI-03
**Mode:** mvp

---

## Goal

Implement the NestJS Antiburla consistency evaluation and biological boundary validation engine:
1. Optimize PostgreSQL schema with composite index on `(user_id, recorded_at DESC)` for sub-15ms 14-day history queries.
2. Implement `AntiburlaService` to scan for prior logs of the same category within the 14-day rolling window when user selects "Começou hoje".
3. Implement biological boundary validator checking biological sex vs anatomical inputs (e.g. female user selecting testicular area).
4. Expose `POST /v1/triage/antiburla-check` endpoint (JWT guarded).
5. Automated unit and E2E test suites.
