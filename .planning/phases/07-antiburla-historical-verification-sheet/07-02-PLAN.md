# Plan 07-02: Screen 5 Antiburla Friendly Bottom Sheet UI with Binary Choice Buttons and Timeline Reconciliation

**Phase:** 7 — Antiburla Historical Verification Sheet (Screen 5 / RF-003 & UC-01)
**Plan:** 07-02
**Requirements covered:** ANTI-02, ANTI-03, I18N-01
**Mode:** mvp

---

## Goal

Implement Screen 5: Antiburla Historical Verification Sheet in Flutter:
1. Intercept Step 2 of the 5-step triage wizard when user selects "Começou hoje" (`comecou_hoje` / `comecou_agora`).
2. Query backend Antiburla check or evaluate local historical logs.
3. If a matching log exists within the 14-day window, present Screen 5 modal bottom sheet with the UC-01 empathetic dialog.
4. Render binary choice buttons:
   - `[É a mesma sensação que voltou]` -> updates answers to `ha_alguns_dias` (recurring discomfort).
   - `[É um sentimento novo]` -> preserves `comecou_hoje` (isolated acute event).
5. Trilingual copy in Brazilian Portuguese (`pt-BR`), Spanish (`es`), and English (`en`).
6. Automated widget tests and hot restart verification.
