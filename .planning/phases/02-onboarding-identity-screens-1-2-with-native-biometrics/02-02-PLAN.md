# Plan 02-02: NestJS AuthModule (Argon2id & LGPD Audit Trail), Screen 2 Simplified Registration & Native Biometric Hardware Security

## Objective
Implement the backend authentication engine in NestJS (`AuthModule`) providing `POST /v1/auth/register`, `POST /v1/auth/login`, and `GET /v1/auth/me` with Argon2id password hashing, short-lived JWT access tokens (15m), and atomic regulatory consent logging in `user_disclaimer_consents` under LGPD Art. 11. Implement **Screen 2: Simplified Registration (AUTH-01 / RF-007)** in Flutter with strict validation for all 5 mandatory fields and non-bypassable LGPD consent gating. Harden the mobile client with native biometrics (`local_auth`), hardware secure storage (`flutter_secure_storage`), `FlutterFragmentActivity` configuration, and an automatic background privacy blur veil (`WidgetsBindingObserver` / AUTH-02).

    - `backend/src/modules/auth/auth.service.ts` implements:
      - `register(dto, clientIp, userAgent)`: checks email uniqueness, hashes password with Argon2id, generates random UUID `newUserId`, hashes client IP with SHA-256, executes single transaction setting `app.current_user_id` to `newUserId`, inserts into `users`, atomically logs consent into `userDisclaimerConsents`, and returns `{ accessToken, refreshToken, user }`.
      - `login(dto)`: executes transaction setting `set_config('app.is_auth_service', 'true', true)`, selects user by email, verifies password via `verifyPassword`, throws `UnauthorizedException` on mismatch, and returns `{ accessToken, refreshToken, user }`.
      - `validateUserById(id)`: retrieves user by id under user RLS context.
    - `backend/src/modules/auth/strategies/jwt.strategy.ts` and `backend/src/modules/auth/guards/jwt-auth.guard.ts` implement Passport Bearer token authentication.
    - `backend/src/modules/auth/auth.controller.ts` exposes:
      - `POST /v1/auth/register` (returns 201 Created)
      - `POST /v1/auth/login` (returns 200 OK)
      - `GET /v1/auth/me` (guarded with `JwtAuthGuard`)
    - `backend/src/modules/auth/auth.module.ts` imports `DatabaseModule`, `JwtModule.register(...)`, and registers `AuthService`, `AuthController`, `JwtStrategy`.
    - `backend/src/app.module.ts` imports `AuthModule`.
    - `backend/test/unit/auth.service.spec.ts` passes:
      - Scenario 1: Happy path registration returns tokens and logs consent.
      - Scenario 2: Unconsented registration (`lgpdConsent: false`) throws `BadRequestException`.
      - Scenario 3: Duplicate email registration throws `ConflictException`.
      - Scenario 4: Login with valid credentials returns tokens.
      - Scenario 5: Login with invalid password throws `UnauthorizedException`.
