# Plan 02-01: Flutter 3.29 Mobile Project Bootstrap, Material 3 Dual Palette Theme, Trilingual Localization Foundation & Screen 1 Onboarding Carousel

## Objective
Bootstrap the **DualisCheckUp** mobile cross-platform client in `mobile/` using Flutter 3.29+ and Dart 3.7+, establish the Material 3 Dual Palette theme system (Soft Indigo `#3F51B5` and Clinical Teal `#00796B`), configure the trilingual `intl` internationalization engine (`pt-BR` default fallback, `es`, `en`) with dynamic runtime switching (I18N-01), build **Screen 1: Onboarding & Auth Choice** with its interactive 3-card value proposition carousel (ONBD-01), and wire GoRouter declarative navigation.

## Context
- Requirements: [ONBD-01, I18N-01]
- Source of Truth: `.planning/phases/02-onboarding-identity-screens-1-2-with-native-biometrics/02-RESEARCH.md` (Sections 1, 2, 6)
- UI Specification: `.planning/phases/02-onboarding-identity-screens-1-2-with-native-biometrics/02-UI-SPEC.md` (Design System, Copywriting Contract, Spacing Scale)

- Depends on: Phase 1 backend baseline (accessible via Dio networking client)
