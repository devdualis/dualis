# Plan 03-02: Screen 8 Emergency Modal, PopScope Lock, Trilingual Copy & Backend Audit

## Objective
Deliver Screen 8 (Emergency Risk Alert Screen - RF-006) as a full-screen red view (`#D32F2F`) locked against dismissal (`PopScope(canPop: false)`), provide 1-tap telephony dispatch (SAMU 192, CVV 188, Bombeiros 193) with tablet fallback dialog, declare complete trilingual copy across pt-BR, es, and en, and wire non-blocking asynchronous LGPD audit telemetry to the NestJS backend.

<threat_model>
| Threat ID | STRIDE Category | Risk | Mitigation Strategy |
|---|---|---|---|
| **T-03-05** | Tampering / Accidental Exit | User accidentally swipes back or presses hardware back button, escaping the emergency screen without medical care. | Enforce `PopScope(canPop: false)`; intercept pops and show non-dismissible (`barrierDismissible: false`) clinical exit warning dialog. |
| **T-03-06** | Denial of Service / Telephony Failure | Wi-Fi tablet or device without cellular modem crashes or does nothing when tapping "Ligar 192". | Check `canLaunchUrl`; if false, render `TelephonyFallbackDialog` with 36pt number and 1-tap clipboard copy. |
| **T-03-07** | Information Disclosure / Cross-Tenant Leak | Emergency event audit logs in backend are readable by other users. | Enforce PostgreSQL RLS policy on `triage_emergency_events` restricting queries to `app.current_user_id`. |
| **T-03-08** | Availability / Latency Spike | Emergency screen rendering or dialer freezes waiting for backend telemetry response. | Telemetry is fired asynchronously via unawaited future (`unawaited(auditService.reportEvent(...))`), completely decoupled from the UI thread. |
</threat_model>

## Must-Haves (Goal-Backward Verification)

### Truths
- Screen 8 renders as a full-bleed emergency red (`#D32F2F`) view.
- Back gestures and hardware buttons are locked by `PopScope(canPop: false)` and require explicit confirmation to exit.
- Tapping SAMU (192) or CVV (188) dispatches phone dialer via `url_launcher`.
- Devices without phone capability show a fallback dialog with copyable number.
- All Screen 8 copy is fully translated in pt-BR, es, and en.
- Emergency alerts are logged asynchronously in the backend without blocking the client.
