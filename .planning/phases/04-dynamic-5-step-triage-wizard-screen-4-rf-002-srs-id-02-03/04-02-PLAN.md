## Goal

Build the complete Screen 4 (`TriageWizardScreen`) UI with:
- Active vertical chromatic banner (300ms smooth `TweenAnimationBuilder<Color?>` transition between Soft Indigo and Clinical Teal).
- Step progress indicator (linear step bar, "Passo X de 5" label).
- Per-step question + selectable answer chip grid.
- Special intensity 1–5 numeric visual selector for Vertical B Step 2.
- Step 4 preview/summary card showing all collected answers before confirm.
- Emergency interception hooked into `selectOption()` (from 04-01) — navigation handled by `EmergencyController`.
- Widget tests verifying rendering and user interactions.

### T5 — Create `TriageWizardScreen` (main scaffold)
**File:** `mobile/lib/features/triage/presentation/screens/triage_wizard_screen.dart` [NEW]  
**Type:** create  

**Structure:**
```
ConsumerStatefulWidget → _TriageWizardScreenState

initState:
  - Read TriageVertical from GoRouterState.extra (default: psicoEmocional)
  - Call notifier.setVertical() in addPostFrameCallback

build:
  - ref.watch(triageWizardNotifierProvider)
  - Derive _activeColor from state.activeVertical
  - Derive _prevColor from previous build (StatefulWidget field)
  - TweenAnimationBuilder<Color?>(
      tween: ColorTween(begin: _prevColor, end: _activeColor),
      duration: const Duration(milliseconds: 300),
      curve: Curves.easeInOut,
      builder: (ctx, color, child) {
        return Scaffold(
          appBar: TriageStepBanner(
            title: active == psicoEmocional
              ? l10n.triageBannerEmotional
              : l10n.triageBannerPhysical,
            currentStep: state.currentStep,
            totalSteps: questions.length,
            activeColor: color ?? _activeColor,
            onBack: () => notifier.goBack(),
          ),
          body: AnimatedSwitcher(
            duration: const Duration(milliseconds: 200),
            child: _buildStepContent(state, questions[state.currentStep], color),
          ),
          bottomNavigationBar: _buildBottomBar(state, color),
        );
      },
    )
```

**`_buildStepContent`:**
- If `isPreview` → `TriagePreviewCard`
- If `isNumericScale` → `TriageIntensitySelector`
- Otherwise → `ListView` of `TriageOptionChip` per option

**`_buildBottomBar`:**
- Shows "Próximo" `FilledButton` (background: `activeColor`) if not preview step
- Shows "Confirmar e Finalizar" `FilledButton` at preview step (calls `notifier.advance()` → `isCompleting = true`)
- Button disabled when `!state.canAdvance`

**Emergency handling:**
- `selectOption` returns `bool emergencyTriggered` from notifier.
- If `true`: do NOT call `advance()`. `EmergencyController` has already pushed `/emergency`.

**autoDispose:** Since `triageWizardNotifierProvider` uses `@riverpod` (autoDispose by default), when `TriageWizardScreen` is popped the provider is disposed and all sensitive health draft data is wiped.
